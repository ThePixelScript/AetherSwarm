# AetherSwarm

> Resilient autonomous multi-UAV coordination for disaster-response missions.

ARES-Swarm is a deterministic, CPU-only Stage-1 simulation framework for autonomous multi-UAV coordination under communication failures, UAV failures, battery constraints, emergency tasks, and safety constraints.

## Stage-1 Claim

Autonomous swarm decision-making validated in a deterministic simulation environment.

## Core Capabilities

- Multi-UAV PoI surveying
- Multi-hop GCS connectivity
- Communication-aware task allocation
- Adaptive relay management
- Fault detection and recovery
- Make-before-break relay handover
- Emergency PoI handling
- Battery-safe RTH
- Collision and geofence safety
- Reproducible scenario-based evaluation
- Baseline-versus-proposed benchmarking
